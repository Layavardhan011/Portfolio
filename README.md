# Layavardhan Reddy — Blockchain Developer Portfolio

Modern, high-performance developer portfolio built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

- **Focus**: Smart Contracts & VM-Executor Engineering (Rust, Go, WebAssembly)
- **Blockchain**: Dharitri Blockchain
- **Live Demo**: Deployed with GitHub Actions & Pages

## Tech Stack
- **Framework**: Next.js (App Router, Static Export)
- **Styling**: Tailwind CSS & Lucide Icons
- **Language**: TypeScript & Rust / Go / WebAssembly
- **Deployment**: GitHub Pages (via GitHub Actions)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Production Build

```bash
npm run build
```
The static export will be generated in the `out/` directory.
